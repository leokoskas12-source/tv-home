# tv-home

Ecran d'accueil personnalise pour TV Samsung Tizen, sous forme de module TizenBrew (type `app`).

## Installation
Sur la TV : TizenBrew -> Module Manager -> ajouter le module GitHub `UTILISATEUR/tv-home`.

## Personnalisation
Edite `app/config.js` : tuiles, identifiants d'apps Tizen (`appId`), image de fond (`bg.jpg` placee dans `app/`).
Les `appId` se lisent sur la TV via l'API ou la documentation Samsung ; les valeurs par defaut sont a verifier.
